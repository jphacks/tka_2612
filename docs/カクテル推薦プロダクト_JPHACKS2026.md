# カクテル推薦プロダクト（JPHACKS 2026 出場作品）

## 概要
カクテルに詳しくない人が、味や内容物（ベース酒・材料）の好みから、自分に合うカクテルを見つけられるプロダクト。
バーや飲み屋で、メニューを見ても何を選べばよいかわからない問題を解決する。

## 想定ユーザー
- 主ユーザー：バーや飲み屋でカクテルを飲む、お酒に詳しくない人
- 店舗側ユーザー：バーや飲み屋の経営者（ユーザーの好みデータを仕入れやメニュー作りに活用する）

## 用語の定義
- **特徴量ベクトル**：お酒の味・内容物の説明文を自然言語処理で数値ベクトルに変換したもの
- **一致度**：ユーザーの好みベクトルと、お酒の特徴量ベクトルの類似度（計算方法は**まだ未確定**。例：コサイン類似度）
- **好み**：ユーザーが入力した味の希望、お気に入りのお酒、フィードバックの総称

## 機能一覧

### 機能① お酒のベクトル化とデータベース作成【Must】
- 各お酒の説明（味、香り、ベース酒、材料など）を自然言語処理でベクトルに変換する
- ベクトルとお酒の情報をデータベースに保存する
- 元データの入手方法・対象とするお酒の数：**【要確認】**
- 使用するモデル（埋め込みモデル）：**【要確認】**

### 機能② メニュー写真からのおすすめ【Must】
- ユーザーがメニューの写真をアップロードする
- 写真からお酒の名前を読み取り、データベースにあるお酒と照合する
- ユーザーが飲みたいお酒の味を入力する
- 読み取れたお酒のうち、ユーザーの好みとの一致度が高いものを、**一致度の高い順に上位5件まで**おすすめする
- データベースにないお酒が写真に含まれていた場合の扱い：**【要確認】**
- 写真の読み取り方法（OCR、画像認識ができるAIなど）：**【要確認】**

### 機能③ 抽象的なリクエストへの対応【Should】
- 「雨上がりに合うお酒」「失恋を支えてくれるお酒」のような、味ではなくシーンや気分を表すリクエストに応える
- 方針の案：リクエスト文もベクトル化して、お酒のベクトルとの一致度で探す
- 出力：一致しているものを**上位5件まで列挙する**
- 機能②（メニュー写真）と組み合わせるか、単独で動かすか：**未確定**

### 機能④ お気に入り・フィードバックの店舗向け提供【Should】
- ユーザーがお気に入りのお酒を登録できる
- ユーザーが推薦結果にフィードバックを返せる
- 集めたデータを、店側が見られる形で提供する（仕入れやメニュー作りの参考にする）
- 個人が特定されない形で提供する（匿名化の方針は**【要確認】**）
- フィードバックを以降の推薦に反映するかどうか：**【要確認】**

## 画面・ユーザーフロー
画面数と流れの案：
1. ユーザーが好みを入力（味の希望や、お酒に入っている内容物、抽象的なプロンプト）
2. メニュー写真をアップロード
3. おすすめのお酒が一致度の高い順に表示される（上位5件）
4. ユーザーがフィードバックを入力する

## データ構造の例
```json
{
  "name": "（お酒の名前）",
  "description": "（味・香り・材料の説明文）",
  "ingredients": ["..."],
  "vector": [0.0, 0.0, 0.0]
}
```
